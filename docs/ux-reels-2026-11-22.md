# UX points from a design-tips account, checked against CLOR — 22 Nov 2026

The owner asked for every post on one UI/UX tips account on Instagram to be read one by one and its
points adopted in CLOR. Signed out, Instagram shows 13 posts (10 reels, 3 picture posts). Each was
read from its caption and, where the caption did not list the points, from frames of the video.
The account's own product plug at the end of each post was ignored.

For each point:
- **Have** means CLOR already does it.
- **Gap** means it should change.
- **Decision** means it goes against a choice in `DESIGN.md` or the owner's, so the owner decides.
- **No** means it does not fit CLOR.

## 1. The perfect dropdown

## 2. Five tells of AI-made dashboards

| Point | CLOR |
|---|---|
| Gradients with nothing to say: use one flat accent | Have: white grounds, no gradients (DESIGN.md) |
| Four colours on four figure tiles: the number is the hero | **No** (owner, 22 Nov, after a side-by-side preview): the Homes keep their tinted icon tiles ("same light accents on every Home", 21 Nov). Figures stay ink; tints sit on icons and meters only. |
| Same size, same weight: one primary figure, the rest secondary | **No** (owner, 22 Nov): Home figures stay one size. |
| Shadow on everything: shadow only on what floats | Have: flat cards, shadow on menus and dialogs only |
| "Welcome back, Jordan 👋" filler copy: numbers with a meaning | Have mostly. Check each Home's greeting line in the next pass. |

## 3. Drag-and-drop uploads

| Point | CLOR |
|---|---|
| The drop zone reacts while a file is over it (border, tint, "Release to upload") | Have since the FileDrop PR: shared `FileDrop` says "Release to attach" on 8 form fields. Toolbar import and photo buttons stay buttons. |
| Honest progress: percent, time left | Name and size shown on every chosen file. Percent left for imports. |
| Inline retry: a failed file says so in place, keeps the file, one tap to retry | Have in `FileDrop` (`error` + `onRetry`); used where a file is read before sending. |
| A file dropped outside the zone must not open in the tab and lose the form | Have: `installStrayDropGuard` in `main.jsx`, the whole app. |
| Several files: one row each, with its own state | **Gap** where more than one file is taken. |

## 6. The input field: six rules

| Point | CLOR |
|---|---|
| Visible label above the field | Have (DESIGN.md Fields) |
| 44px tall and 16px text | **Gap on phones**: 44px and 16px only inside the employee app's `.ui-touch-44` sections. Elsewhere a phone gets 36px fields with 14px text, and Safari zooms into them. Desktop stays 36px (DESIGN.md). |
| A real focus ring | Have: 3px app colour at 28% |
| Field border at 3:1 against white | Have since 22 Nov (owner: yes): fields take `--border-input` `#949494`, 3.0:1. Cards and secondary buttons keep `#D6D6D6`. |
| Errors after blur, not while typing | Have (`useFieldErrors`: blur sets or clears) |
| The right keyboard (`inputMode`, `type="email"`, `type="tel"`) | Have on about 200 fields. Check the rest in the next pass. |

## 7. Card shadows

| Point | CLOR |

## What happens next

1. **Now:** phones get 44px controls and 16px field text everywhere, not only in the employee app. DESIGN.md already says "44px on phones".
2. **Done:** one shared file drop field (`FileDrop`).
   - The zone reacts to a dragged file.
   - It shows the file's name and size.
   - A failure says so in place, keeps the file and offers a retry.
   - Several files get one row each.
   - A stray drop doesn't open the file in the tab.

   It replaces the 23 hand-built pickers.
3. **Owner decisions (settled 22 Nov):** the owner saw tinted, plain, and plain with one main figure side by side and kept the tints with equal figures. Nothing changes on the Homes.

## 14. Calm dashboards you can act on (second account, owner's pick)

The owner sent one more reel (a fintech dashboard) and asked for People Home to work like it. A preview was built and approved ("Build it", 22 Nov). Taken: the screens and structure. Left out: its palette and fonts.

| Point | CLOR |
