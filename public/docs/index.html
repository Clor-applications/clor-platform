Help

Setting CLOR up alongside what you already run: readers, HR tools, Tally, your identity provider.

Guides

  • Readers — ZKTeco/eSSL (ADMS), Matrix COSEC, Hikvision, Dahua, Suprema, Anviz, e-Time Office, any software that can send or serve punches, CSV import.
  • On-site connector — readers on the office network, Tally on your LAN, Active Directory.
  • HR tools — greytHR, Keka, Zoho People: punches out, people in.
  • Tally — payroll entries as import XML, or posted straight into Tally.
  • Single sign-on — Google Workspace, Microsoft Entra, Okta, ADFS (OpenID Connect and SAML 2.0).
  • Directory sync (SCIM) — your identity provider adds and removes people in CLOR.

Where things are in CLOR

WhatWhere
Readers, their health, logsAttendance → Readers
Webhooks, HR tools, on-site connectorsAttendance → Settings → Integrations
API keys and tokensWorkspace → Security → Credentials
Single sign-on, directory syncWorkspace → Security → Single sign-on
Tally exportPayroll → Pay runs → open a run → Books

Everything else — companies, people, roles, security, plan, data — is in the Help centre inside CLOR: open Help at the foot of the Workspace rail, or the help icon in any app.
