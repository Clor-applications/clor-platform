Tally

A payroll run’s accounting entry, the way Tally imports it.

As a file

Payroll → Pay runs → open a run → Books → “Tally XML”. The file holds one Journal voucher dated the period end, with CLOR's ledger names. In Tally: Gateway of Tally → Import Data → Vouchers, choose the file. Ledger names must exist in the Tally company by the same name; Tally says which one is missing.

Straight into Tally

With an on-site connector set up with Tally's address, the same screen offers “Send to Tally via …”. The connector posts the voucher to Tally's HTTP port and reports Tally's answer (created, or the ledger it refused) under the connector's Jobs.

Before it balances

Every salary component needs an expense ledger (and deductions a liability ledger) under Payroll → Ledger mapping; the Books stage lists what is unmapped. Nothing is exported until the entry balances.
